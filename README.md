# Fit Pakistan — customized Android prototype

A local-first Android app concept based on the user's 30-day fat-loss plan.

## Personal baseline
- Male, 30, 173 cm, 92 kg; target ~80 kg
- Fat loss while preserving/building muscle
- Starting nutrition target: ~2,200 kcal/day, ~150 g protein, 65–75 g fat, 220–250 g carbs, 30–35+ g fiber
- Steps: 5k → 6k → 7k → 7–8k
- Cardio: ~90–120 → 150–180 min/week, low-impact, RPE 3–5
- Base training: 4-day Upper/Lower (Days 1,2,4,5)
- Heel/foot-pain-aware cardio and exercise modifications

## Included prototype features
- Daily dashboard with calorie/protein/water/steps remaining
- Pakistani meal logging with common foods and rough calories/protein
- Custom meal calories + protein
- Water logging and repeating 2-hour reminder
- 4-day Upper/Lower workout logic plus active recovery
- Exercise completion checkboxes
- Low-impact cardio logging
- Weight check-ins
- Daily coaching messages designed to avoid crash dieting / compensatory exercise

## Build
Open in Android Studio and run on an Android 8.0+ device/emulator. The environment used to generate this prototype does not include the Android SDK/Gradle distribution, so an APK could not be compiled here.
